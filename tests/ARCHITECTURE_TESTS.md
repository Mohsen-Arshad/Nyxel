# Acceptance tests

- [ ] Gateway starts without credentials.
- [ ] Provider definitions import/export without secrets.
- [ ] Invalid executable provider fields are rejected.
- [ ] User can override routing.
- [ ] Unhealthy provider is excluded and fallback is attempted.
- [ ] Secret files are excluded from context.
- [ ] Cancellation reaches the active provider transport.
- [ ] Streaming events are emitted in order.
- [ ] Browser provider has isolated profile storage.
- [ ] Provider repair requires a successful test before save.
- [ ] VS Code remains usable when gateway/provider fails.
- [ ] No raw prompt or credential is written to logs.
